# Windows 原生调用

- Win32 的指针转 `uintptr` 必须发生在带 `//go:uintptrescapes` 的调用点；保留 `call()` 的指令，不能用普通包装函数中转这些参数。窗口和钩子的创建、消息循环保持在各自锁定的 OS 线程。
- 启动必须提供可见设置入口；首次托盘添加失败应提示并退出，重复启动唤起已有实例的设置。保留 `TaskbarCreated` 图标恢复处理。
- 构建与验证沿用根目录 `README.md`。macOS 的交叉编译及 Windows 测试可执行文件生成不等于 Windows 托盘、窗口或输入钩子的实机验证。
- 诊断保存对话框及结果提示只在 UI 线程运行；网络线程生成脱敏快照后交给独立任务写入用户选择的路径，不能让慢盘或模态提示阻塞同步。输入钩子只原子累积固定的连续性中断原因，由网络线程写入内存诊断。
- 无人值守 CI 使用 `go test ./...` 覆盖离线自测及原生 ABI；GUI `--self-test` 会弹出模态消息框，不能在 Actions 中运行。
